# More than a Hack 2027 — Ball Possession Model

## Regenerate Submission

1. Install pinned dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Place the official match files under `data/tactical/` and `data/broadcast/`.
3. Run the model to generate `possession_file.csv`:
   ```bash
   python model/final_model.py
   ```
